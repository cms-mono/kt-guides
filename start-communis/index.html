00사이트 주소

URL ↗ https://communis.kt.co.kr/

01회원가입

오너계정이 아닌 추가 사용자 계정 생성 시 아래와 같이 진행하시기 바랍니다.

  • 커뮤니즈 사이트에서 회원가입 페이지›법인사업자 안내에 따라 가입 진행하시면 됩니다.
필요 서류
  • 사업자등록 사본
  • 법인 인감증명서
  • 위임장
  • 담당자 신분증 사본
ℹ
최초 회원가입 이후 다시 회원가입 페이지에서 사업자 등록번호 기입 시 일반멤버로 추가 회원가입 가능합니다.(서브 담당자 등록 시 사용)
참고 ↗ https://communis.kt.co.kr/guide/startGuide.do?menuIndex=2

02서비스 신청 방법

  1. 로그인 후 커뮤니즈 메인 페이지 상단 메뉴›대시보드 버튼 클릭
  2. 서비스 관리›서비스 신청 하기 메뉴에서 서비스 신청이 가능합니다.
    !
    서비스 신청 전에 결제서비스›청구계정 정보 메뉴에서 청구계정 등록이 필요합니다.
  3. 서비스명, 청구정보 작성하시고, API 선택에서 를 선택하여 신청하시면 됩니다.
참고 ↗ https://communis.kt.co.kr/guide/startGuide.do?menuIndex=5

03서비스 등록 정보 조회

  • 서비스 관리›서비스 등록 정보 메뉴에서 신청한 서비스 조회가 가능합니다.
